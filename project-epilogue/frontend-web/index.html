📜 《暗流》全域指南與 13 位男主角色圖鑑

探索自由抉擇機制、三層人設注入、長效記憶架構與 13 位官方男主檔案。

✦ 1. 無預設腳本 · 100% 原創即時長篇創作

《暗流》摒棄傳統文字遊戲預先寫好的固定分支。每一次回合推進，皆由無審查長篇專用大模型根據您的個人人設、抉擇與自訂輸入，現場即時創作 1,000 ~ 1,500 字 沉浸式長篇小說正文。

✦ 2. 多重博弈與自由行動輸入

每一回合系統均為您提供 3 個策略選項，並附帶風險提示：

  • [A] 穩健推進 (Low Risk)：在規則內步步為營，鞏固情報與底牌。
  • [B] 言語試探 (Medium Risk)：話術機鋒拉扯，探查對方底線。
  • [C] 極限誘惑/破局 (High Risk)：打破常規、傾身靠近、點燃性張力與衝突。
  • ⚡ 自由行動輸入：在底部的文字輸入列中，輸入任何您想說的對白、肢體碰觸或突發行動，AI 將完全接續您的意志推演！

✦ 3. 政治、商戰、情慾與奇思異想的交織

遊戲涵蓋政界暗潮、法務地檢交鋒、百億集團商戰、黑道殺伐、私密診所支配、頂流偶像情感拉扯與露骨細緻的成人情慾 (R-18)。您可以選擇專攻單一男主，亦可開啟全勢力修羅場，體驗多方爭霸與情感修羅場！

🎭 1. 三層角色動態注入引擎 (Tiered Lore System)

  • Tier 1（核心攻略主角）：全量常駐完整的官方身分、MBTI、穿搭與嚴格身分防火牆（例如徐令謙絕不是檢察官，韓正寰才是白日判官）。
  • Tier 2（動態在場配角）：一旦小說正文或您的對白中提及背景人物（如韓檢、林次、副總統），系統即刻從記憶體/雲端載入其全量完整 Markdown 設定，以配角身分在場推動衝突，絕不喧賓奪主。
  • Tier 3（世界全景名冊）：其餘 11+ 位男主以勢力名冊常駐，世界持續在背景運轉利益暗流，絕不被世界遺忘。

🧠 2. 長期滾動摘要池與雙軌記憶 (Rolling Summary Pool)

下筆前必讀「歷史滾動摘要池」＋「近期 2 回合對話」。每逢 5 的倍數回合（第 5、10、15 回...），背景將自動調用輕量模型（1.5 秒）將歷史脈絡濃縮為高密度大事紀，確保長篇小說在百回後仍邏輯連貫、伏筆不丟失。

💾 3. 存檔庫管理與手動同步至雲端（可跨裝置遊戲）

支援無限自訂命名的存檔插槽，隨時可重新命名、搜尋、讀取載入或刪除。同時支援【手動同步至雲端（可跨裝置遊戲）】，保障進度永不遺失並可在手機與電腦無縫接續遊玩。
